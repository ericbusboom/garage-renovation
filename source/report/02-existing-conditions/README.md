# 02 — Existing Conditions

This section establishes the physical and legal starting point: licensed boundary/topographic survey, measured garage and outbuilding, utilities and overhead lines, site drainage and grades, vegetation, keyed photographs, condition assessment, and permit history.

Photo-derived CAD models are useful references but do not substitute for a survey or destructive/field investigation. Show uncertainty explicitly.

## Required outputs

- boundary and topographic survey
- existing-condition architectural drawings and editable model
- structural condition assessment
- utility/overhead-line exhibit
- tree and vegetation inventory
- keyed photo log
- existing permit/history record
