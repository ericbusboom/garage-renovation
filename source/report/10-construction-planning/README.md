# 10 — Construction Planning

This section explains how the new structure can be built around the existing garage and how the old roof can be removed safely. It covers demolition, erection, temporary works, access, lifting, utility and tree protection, weather protection, inspection hold points, and site logistics.

Conceptual sequence diagrams do not authorize construction. Temporary supports and erection stability must be designed for the actual sequence.

## Required outputs

- demolition and phasing plan
- engineered shoring/temporary-bracing/erection criteria
- site logistics and lifting plan
- utility, property, vegetation, occupant, and weather protection plan
- inspection/test plan and hold-point schedule
