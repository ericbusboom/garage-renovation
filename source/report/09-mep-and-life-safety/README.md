# 09 — MEP and Life Safety

This section contains electrical distribution and lighting, ventilation or conditioning, any plumbing/drainage systems, and the code features required for safe use: egress, doors, stairs or ladder, guards, fall protection, alarms, fire separation, and emergency controls.

Requirements depend on the upper level's legal use and must be revisited when that use is fixed.

## Required outputs

- electrical and lighting plans/schedules
- ventilation or mechanical design, if required
- plumbing/drainage plans, if required
- code and life-safety plan
- fire-resistance, alarm, egress, and guard details
