# Renders

Blender files and other rendered presentation packages live here. Package directories use `YYYYMMDD.NN-<slug>`.

Renders are illustrative unless a corresponding artifact has been promoted and assigned a status in the controlled report.

Site photographs (`references/`), final render PNGs and their texture sources are tracked in git because they cannot be regenerated cheaply. Previews, test images, `.glb` browser copies and `*-mesh.json` inputs stay git-ignored; each package README says how to rebuild them.
