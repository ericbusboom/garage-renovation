# 05 — Architectural Design

This section contains the selected architectural scheme and coordinated geometry. It includes site/demolition plans, floor and roof plans, elevations, sections, enlarged details, schedules, materials, and explanatory renderings.

Alternatives stay in working folders unless a concise comparison is needed to explain a recorded decision.

## Required outputs

- design narrative
- architectural drawing set
- native editable and neutral exchange models
- door, window, finish, room/use, and equipment schedules
- selected renderings labeled as illustrative
