# Controlled Deliverables

This directory is intentionally empty until a coordinated package is issued for a named purpose.

Each package must include:

- cover/index with issue purpose, date, revision, and contents;
- the current drawings, reports, calculations, specifications, and schedules required for that issue;
- editable native models and neutral exchanges when included in scope;
- manifest extract and checksums;
- a list of known limitations or deferred items.

Do not place a file here merely because it is the most recent output.
