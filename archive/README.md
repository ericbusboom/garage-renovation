# Project Archive

This directory preserves material removed from the project root during the 2026-09-21 reorganization. It is recoverable history, not the current working structure.

Active material was reviewed and moved into `report/`, `studies/`, `data/`, `viz/`, `render/`, `plans/`, `src/`, and `public/`. The garage site output was promoted from the earlier publication mirror into `public/`; the items retained here are local tooling, caches, superseded notes, loose concept images, publication source, and unrelated mirror content. See `reorganization-manifest.csv` for the move record.

Do not treat an archived file as approved or current merely because it is newer than another file. Controlled status remains in `report/document-manifest.csv`.

The pre-versioning visualization tree, including the nested development options
formerly under `viz/structural-analysis/s3-removal/`, was moved to
`20260924.01-viz-cleanup/legacy-structural-analysis/`. The selected successor is
identified by `viz/latest`, not by anything in this archive.
